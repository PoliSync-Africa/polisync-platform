# POLISYNC AFRICA — Design System (Skin, Theme & Dark Mode)

**Version:** 1.0 (Founder Blueprint)

---

# Purpose

The POLISYNC Design System establishes the official visual identity of the platform. It ensures every screen—from Login to Election Results—uses a consistent appearance, making the platform recognizable, accessible, and professional across Africa.

The design philosophy is:

> **"A Secure Political Command Center."**

---

# Design Principles

Every interface must be:

- Professional
- Trustworthy
- Mobile-first
- Fast
- Accessible
- Consistent
- Easy to use during high-pressure election periods

# Theme Modes

POLISYNC supports three official themes.

## Theme 1 — Command Dark (Default)

The default experience.

Best for:

- Campaign operations
- Election monitoring
- Night usage
- Command centers

### Appearance

- Midnight Navy background
- Deep Blue cards
- Gold highlights
- White typography
- Soft glowing accents

Example:

Background: `#071B34`

Cards: `#0E2A4D`

Buttons: `#F5B400`

---

## Theme 2 — Professional Light

Designed for daytime office work.

### Appearance

- White background
- Light Gray surfaces
- Navy text
- Gold action buttons

Best for:

- Administrators
- Office environments
- Long working sessions

---

## Theme 3 — Election Night Mode

POLISYNC's signature experience.

Automatically activates during election monitoring (or manually).

### Features

- Live glowing dashboards
- Animated vote counters
- Gold verification badges
- Pulsing constituency updates
- Real-time reporting indicators

This becomes POLISYNC's unique visual identity.

# Animations

Animations should feel professional.

Use:

- Fade In
- Slide Up
- Smooth Transitions

Avoid excessive motion.

# Accessibility

POLISYNC follows accessibility-first design.

Requirements

- High color contrast
- Large touch targets
- Screen reader labels
- Keyboard navigation
- Scalable text

Minimum touch target:

44×44 pixels.
